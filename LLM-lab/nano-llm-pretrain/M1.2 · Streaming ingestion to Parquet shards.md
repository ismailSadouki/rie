# Why Parquet?

Instead of

```
Internet
↓

FineWeb
↓

Training
```

(which means downloading the same data every time),

you do

```
Internet
↓

FineWeb

↓

Your preprocessing

↓

Parquet shards

↓

Everything else
```

Now tokenizer training, filtering, statistics, and model training all read **your local Parquet dataset**.

# What you should learn in M1.2

There are four ideas.

## 1. Streaming

Already covered.

```python
dataset = load_dataset(
    "HuggingFaceFW/fineweb",
    split="train",
    streaming=True,
)
```

---

## 2. Buffering

Don't write one document at a time.

Bad:

```python
for sample in dataset:
    write_parquet(sample)
```

Imagine writing to disk **1 million times**.

Very slow.

Instead

```python
buffer = []

for sample in dataset:
    buffer.append(sample)

    if len(buffer) == 10_000:
        save(buffer)
        buffer.clear()
```

Much faster.

---

## 3. Sharding

Instead of

```
fineweb.parquet
```

make

```
shard_00000.parquet
shard_00001.parquet
shard_00002.parquet
...
```

Each shard might contain

```
10,000 documents
```

or

```
100 MB
```

Why?

Because later

```
Tokenizer
```

can process shards independently.

Training can process shards independently.

Statistics can process shards independently.

Everything scales.

---

## 4. Stop condition

You do **not** want all FineWeb.

Instead

```
tokens = 0

while tokens < 200M:
```

or

```
documents = 500000
```

then stop.

## A small recommendation

Since this repository aims to demonstrate a production-style pipeline, I'd make **M1.2 as generic as possible**. Don't hardcode `"HuggingFaceFW/fineweb"` throughout the code. Instead, let `configs/data_filter_v0.yaml` (or a dedicated ingestion config) specify things like:

- dataset name
    
- split
    
- output directory
    
- documents per shard
    
- target token budget
    
- columns to keep
    

Then `scripts/ingest.py` simply reads the configuration and runs the pipeline. That small design choice will make it much easier to reuse the ingestion stage later with a different corpus, such as an Algerian Darija dataset, without changing the code.

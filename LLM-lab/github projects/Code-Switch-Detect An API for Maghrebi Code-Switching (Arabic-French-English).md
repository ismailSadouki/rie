- **Description:** A lightweight, high-speed tool to segment and identify language shifts in a single sentence.
- **Target Users:** Data engineers cleaning datasets for training.
- **Why people care:** Cleaning Darija data is a nightmare because of the mixed scripts and languages.
- **GitHub/Traction:** It’s a "utility tool"—developers love utilities that save them time.
- **MVP:** A FastAPI tool that takes a string and returns a language map.
- **Architecture:** Small DistilBERT or even specialized RegEx/FastText combo.
- **Compute:** Can be trained on your RTX 3050.
- **Difficulty:** 4/10.

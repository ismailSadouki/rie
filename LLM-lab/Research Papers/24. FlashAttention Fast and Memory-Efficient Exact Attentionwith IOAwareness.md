

**Attention isn't slow because of too many operations. It's slow because of too many memory trips. FlashAttention fixed the right problem.**

This is the insight that makes the FlashAttention paper (Dao et al., 2022) so elegant. Prior work on efficient attention focused on reducing the number of floating point operations — linear attention, sparse attention, various approximations. They looked good on paper but rarely produced real-world speedups. FlashAttention asked a different question: where is the actual time going on a real GPU?

The answer is memory bandwidth. Standard attention requires materializing the full N×N attention matrix in GPU high-bandwidth memory (HBM) — reading and writing it multiple times during the forward pass. For long sequences, this becomes the dominant cost, not the compute itself. The GPU's compute units sit idle waiting for data to arrive.

FlashAttention's fix: never materialize the full attention matrix at all. Instead, tile the computation into blocks that fit entirely in the GPU's fast on-chip SRAM, compute attention block by block, and accumulate results — all without touching slow HBM unnecessarily. The math is identical to standard attention. The output is bit-for-bit exact. Only the memory access pattern changes.

The results are striking: 3× speedup on GPT-2, 15% end-to-end speedup on BERT-large against the MLPerf training record, and — crucially — it enables context lengths that were previously computationally infeasible, with the first transformers to achieve better-than-chance on Path-X at sequence length 64K.

The honest contribution framing: FlashAttention isn't an approximation. It's a rewrite of how exact attention is computed, optimized for how GPUs actually work rather than how we abstractly think about them.

**Why it matters now:** FlashAttention is in PyTorch's `scaled_dot_product_attention` natively, used by default in every major training framework, and is the reason context windows exploded from 2K to 128K+ in the last three years. If you've trained or fine-tuned any transformer — including on Darja data — you've used this. Understanding it is the difference between someone who uses GPU abstractions and someone who understands what's actually happening on the hardware.

_Dao et al., 2022 — "FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness" — arxiv.org/abs/2205.14135_

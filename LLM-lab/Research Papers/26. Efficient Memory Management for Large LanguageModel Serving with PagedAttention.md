

**GPUs are expensive. When serving LLMs in production, up to 60-80% of GPU memory gets wasted before a single user request is even processed. PagedAttention is the paper that fixed that.**

The culprit is the KV cache — the stored keys and values for every token in every active sequence. To avoid recomputation, serving systems pre-allocate a contiguous memory block for each request's maximum possible length. But sequences finish early, grow unpredictably, and vary wildly in length. The result: massive internal and external memory fragmentation, the same problem operating systems solved for RAM decades ago.

The vLLM paper (Kwon et al., 2023) borrowed the solution directly from OS virtual memory: paging. PagedAttention divides the KV cache into fixed-size blocks — pages — that don't need to be contiguous in physical GPU memory. A block table maps each sequence's logical KV positions to physical memory blocks, allocated on demand as the sequence grows. No pre-allocation, no wasted headroom, no fragmentation.

The practical consequences are dramatic. Memory utilization jumps from roughly 20-40% with existing systems to near 100%. That directly translates to throughput: vLLM serves 2-4× more requests per second than HuggingFace Transformers and 1.8× more than FasterTransformer on the same hardware. The paper also shows that paging enables efficient memory sharing across requests — for beam search and parallel sampling, multiple sequences can share the same KV cache pages for their common prefix, with copy-on-write semantics when they diverge.

The honest limitation: PagedAttention adds indirection — the block table lookup — into the attention kernel's memory access pattern. This complicates kernel implementation and can interact awkwardly with FlashAttention's tiling strategy. Getting both working together efficiently required significant engineering effort.

**Why it matters now:** vLLM is the dominant open-source LLM serving engine in 2026. If you've hit a production inference system — whether a hosted API or a self-deployed model — there's a high probability PagedAttention is managing its memory underneath. For anyone building real serving infrastructure, this paper is as important as FlashAttention. Together they define how modern LLM serving actually works.

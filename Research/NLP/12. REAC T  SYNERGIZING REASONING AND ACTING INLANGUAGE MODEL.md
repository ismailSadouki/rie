
**Chain-of-thought taught LLMs to reason. ReAct taught them to act on that reasoning.**

That's the conceptual jump in the ReAct paper (Yao et al., 2022) — and it's the jump that made the current agent era possible.

The problem with pure chain-of-thought: the model reasons entirely inside its own head, using only what it already knows. No external verification. No fresh information. Which means it can hallucinate confidently, propagate errors across reasoning steps, and have no way to course-correct.

ReAct's fix is elegant: interleave reasoning traces with actions. The model thinks, then acts — calling a tool, querying a Wikipedia API, interacting with an environment — then observes the result, then thinks again. Thought → Action → Observation → Thought. Each loop grounds the reasoning in something external and real.

The results on HotpotQA and FEVER are significant: ReAct substantially reduces hallucination compared to chain-of-thought alone, because the model can check its beliefs against an external source before committing to them. On interactive decision-making tasks like ALFWorld, it outperforms reinforcement learning baselines by 34% in absolute success rate — using just one or two in-context examples.

The honest limitation: ReAct as described is brittle. It depends on well-formatted tool outputs, can get stuck in repetitive loops, and has no built-in mechanism to recover from a bad action. Later work like Reflexion added self-critique layers on top to address exactly this.

**Why it matters now:** Every AI agent you interact with in 2026 — whether it's Claude with tools, a coding agent, or an autonomous research assistant — runs on some version of this loop. ReAct didn't just introduce a prompting trick; it defined the architecture of agentic AI. If you're building RAG systems or agents, this is required reading.

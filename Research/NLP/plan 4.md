LangChain/LlamaIndex are wrappers. They hide the model, they don't expose it. 2. **Deep Dive into CUDA:** Writing a full attention kernel in raw CUDA takes weeks and is constantly broken by GPU architecture shifts. **Write Triton instead.** It’s 10x faster to learn, OpenAI uses it internally, and it proves the same memory hierarchy mastery. 3. **Megatron-LM & DeepSpeed:** These are legacy frameworks built for specific cluster topologies. PyTorch FSDP is the native, modern standard. Learn FSDP first; Megatron later if you join a massive pretraining team. 4. **Kaggle:** It teaches you to overfit to public leaderboards using hacky prompts. It teaches you zero about distributed systems or memory optimization. 5. **RLHF (PPO):** PPO is notoriously unstable, requires 4 models running simultaneously, and takes massive compute to tune. DPO is the direct, mathematically sound alternative that the industry has largely adopted. Implement DPO. --- ### The 3-5 Projects (Your Portfolio Core) Do not build chatbots. Build infrastructure and training loops. 1. **Pretrain a 1.5B GPT from scratch (Data $\rightarrow$ FSDP $\rightarrow$ Eval):** * *Why:* This is the ultimate differentiator. It forces you to build the data pipeline (tokenizers, packing), handle distributed crashes (NCCL, OOM), stabilize loss spikes, and write an eval loop. If you can do this, you can do 90% of LLM engineering jobs. 2. **Implement DPO from Scratch (Pure PyTorch):** * *Why:* Alignment is the current frontier. Doing this without TRL forces you to understand logprob handling, reference model freezing, and the exact tensor math of the DPO loss. It proves you can translate papers directly to stable GPU code. 3. **Write a Custom Triton Kernel (e.g., Fused RoPE or RMSNorm):** * *Why:* Most engineers treat the GPU as a black box. Writing a kernel that actually runs faster than PyTorch native proves you understand SRAM/HBM memory hierarchy and arithmetic intensity. This alone gets you interviews at inference teams. 4. **Deploy a 70B Model with vLLM & Load Test it:** * *Why:* Training is expensive, inference is where money is made. Deploying vLLM, configuring continuous batching, and writing a Locust script to saturate it proves you understand the end-to-end lifecycle. 5. **Merge 1 PR to vLLM or Unsloth:** * *Why:* A merged PR to a top-tier production repo is the strongest signal of elite competence. It proves you can read complex code, find a bug/perf bottleneck, and write code that meets another engineer's strict standards. --- ### The 12-Week Crucible (Your Roadmap) Assume 8 hours/day.



**In January 2025, a Chinese lab released a reasoning model that matched OpenAI o1 — trained with pure RL, no human-annotated reasoning traces, and open-sourced weights. The field had to pay attention.**

That's DeepSeek-R1 (DeepSeek-AI, 2025), and it's one of the most consequential papers of the last two years.

The story starts with R1-Zero — an experiment where they applied reinforcement learning directly to a base model with zero supervised fine-tuning. No human-written chain-of-thought examples. No labeled reasoning trajectories. Just a rule-based reward signal: is the final answer correct? Is the format right? Nothing else.

What emerged was striking. The model spontaneously developed self-verification, reflection, and dynamic strategy exploration — including an "aha moment" where it learned to pause and reconsider its own reasoning mid-generation, producing outputs like "Wait, let me reconsider..." Nobody taught it that. The behavior emerged from the reward signal alone.

R1-Zero had problems though — poor readability and language mixing. So they built DeepSeek-R1 on top: a multi-stage pipeline with cold-start data and two rounds of RL, producing a model that matches o1 on math, coding, and STEM reasoning benchmarks.

The honest limitation: rule-based rewards only work when correctness is verifiable. Math has a right answer. Code either runs or it doesn't. For open-ended tasks — writing, judgment, nuanced reasoning — this training signal breaks down entirely. RL for reasoning is still largely limited to domains where you can check the answer automatically.

**Why it matters now:** DeepSeek-R1 did three things simultaneously: proved that reasoning can emerge from pure RL without human demonstrations, matched a frontier closed model, and released the weights openly. It democratized reasoning model research overnight and triggered a wave of replication attempts across every major lab. If you're studying LLMs in 2026, this paper is not optional.

_DeepSeek-AI, 2025 — "DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning" — arxiv.org/abs/2501.12948_

# 1. What is R1-Zero?

DeepSeek-R1-Zero is a reasoning model obtained by applying **GRPO reinforcement learning directly on DeepSeek-V3 Base**, **without any supervised fine-tuning (SFT)**.

Pipeline:

```text
DeepSeek-V3 Base
        │
        ▼
GRPO RL
        │
        ▼
DeepSeek-R1-Zero
```

Characteristics:

- No cold-start demonstrations.
    
- No human-written reasoning traces.
    
- Only a simple output format (`<think>...</think><answer>...</answer>`).
    
- Uses **rule-based rewards** (correctness + format).
    

---

# 2. Why did RL alone produce reasoning?

The reward only evaluates the **final answer**, not the reasoning.

For each question:

```
Question
```

↓

Generate multiple reasoning traces.

↓

Rule-based reward:

- Correct answer → high reward.
    
- Wrong answer → low reward.
    

↓

GRPO increases the probability of trajectories that obtain higher rewards.

Over many RL updates, the policy discovers that:

```
Longer
More careful
Self-checking
Multi-step reasoning
```

produces higher expected rewards than shallow reasoning.

Therefore reasoning **emerges naturally** because it is an effective strategy for maximizing reward.

No human explicitly teaches the reasoning steps.

---

# 3. Why was R1-Zero not sufficient?

Although reasoning emerged, R1-Zero had several practical problems.

Main issues:

- Language mixing (English + Chinese in the same CoT).
    
- Poor readability.
    
- Inconsistent formatting.
    
- Weak general assistant abilities.
    
- Not well aligned with human preferences.
    

So R1-Zero was an excellent proof of concept but **not a production-quality assistant**.

---

# 4. Why did they introduce the full DeepSeek-R1 pipeline?

To fix the weaknesses of R1-Zero while preserving its reasoning ability.

Pipeline:

```text
DeepSeek-V3 Base
        │
        ▼
RL
        │
        ▼
R1-Zero
        │
Generate reasoning traces
        │
Filter + Human refinement
        │
Cold-start dataset
        │
        ▼
SFT
        │
        ▼
Dev-1
        │
        ▼
RL
        │
        ▼
Dev-2
        │
Generate more data
        │
        ▼
SFT (Reasoning + General tasks)
        │
        ▼
Dev-3
        │
        ▼
Final RL
        │
        ▼
DeepSeek-R1
```

Each stage fixes a different weakness:

- Cold-start SFT → readability.
    
- Second RL → stronger reasoning.
    
- Second SFT → recover general assistant abilities.
    
- Final RL → helpfulness and safety.

# 5. How is DeepSeek-R1 different from classical RLHF?

### Classical RLHF (InstructGPT)

```text
Pretrained Model
        │
        ▼
SFT
        │
        ▼
Reward Model
        │
        ▼
PPO
```

Requires:

- Human demonstrations.
    
- Human preference pairs.
    
- Reward model.
    
- PPO with a value model (critic).
    

---

### DeepSeek-R1

Reasoning stage:

```text
Pretrained Model
        │
        ▼
GRPO
```

Uses:

- Rule-based rewards.
    
- No critic.
    
- No neural reward model for reasoning.
    
- Group-relative advantages instead of a value network.
    

Only the final alignment stage uses reward models for:

- Helpfulness.
    
- Safety.
    

---

# 6. Why no reward model for reasoning?

Because reasoning tasks (math, coding, logic) have objective answers.

Example:

```
2+2=4
```

Correctness can be checked automatically.

Advantages:

- No human preference labels.
    
- No reward model training.
    
- Less reward hacking.
    
- Precise supervision.
    

---

# 7. What rewards are used?

## R1-Zero

Rule-based rewards:

- Accuracy reward.
    
- Format reward.
    

---

## Intermediate RL

- Rule-based reward.
    
- Language consistency reward.
    

---

## Final RL

Reasoning tasks:

- Rule-based reward.
    

General tasks:

- Helpfulness reward model.
    
- Safety reward model.
    
- Format reward.
    

Overall:

# [  
R

R_{reasoning}  
+  
R_{general}  
+  
R_{language}  
]

where only the relevant terms are applied to each sample.

# 8. Why is distillation important?

R1 is very large.

Most users cannot deploy it.

Instead:

```text
DeepSeek-R1 (Teacher)
        │
Generate reasoning traces
        │
        ▼
SFT
        │
        ▼
Small model (Student)
```

The student learns R1's reasoning behavior through supervised learning.

Benefits:

- Much smaller models.
    
- Faster inference.
    
- Lower memory requirements.
    
- Strong reasoning without RL.
    

---

# 9. Main contributions of the paper

1. Demonstrated that **RL alone** can induce reasoning.
    
2. Introduced **R1-Zero** as a proof that reasoning can emerge from outcome-based rewards.
    
3. Built the **DeepSeek-R1 multi-stage pipeline** combining SFT and RL.
    
4. Used **GRPO**, eliminating the need for a critic.
    
5. Used **rule-based rewards** for reasoning instead of neural reward models.
    
6. Showed that reasoning abilities can be **distilled** into much smaller models.

**A Testing Strategy**

We have just seen how the problem of autocorrelation of errors was addressed in the context of the model without a constant or a trend (3.4). The same solutions can be recommended for the model with a constant (3.5) and the model with both a constant and a trend (3.6).

However, assuming that a stochastic process is generated by one of these three models (without knowing which one), testing the null hypothesis ( H_0: \rho = 1 ) does not allow us to assert the existence of a unit root on the basis of a single model. Nor is it possible to distinguish between a trend-stationary (TS) process and a difference-stationary (DS) process on the basis of a single model.

To _hope_ to reach a correct conclusion, it is necessary to use the Dickey–Fuller testing strategy, which combines the test of the simple null hypothesis ( H_0: \rho = 1 ) with joint hypothesis tests ( H_{01} ), ( H_{02} ), and ( H_{03} ).

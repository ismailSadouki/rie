The 2014 Workshop on Machine Translation (WMT) contained several European
language datasets. One of the datasets contained data taken from version 7 of the
Europarl corpus. We will be using the French-English dataset from the European
Parliament Proceedings Parallel Corpus 1996-2011. The link is https://www.statmt.org/europarl/v7/fr-en.tgz.
We will load, clear, and reduce the size of the corpus.

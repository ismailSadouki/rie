# Community Adoption
Auto-WEKA was the first method to use Bayesian optimization to automatically
instantiate a highly parametric machine learning framework at the push of a
button. Since its initial release, it has been adopted by many users in industry and
academia; the 2.0 line, which integrates with the WEKA package manager, has been downloaded more than 30,000 times, averaging more than 550 downloads a week. It is under active development, with new features added recently and in the pipeline.

The ability to generate human-readable reports is perhaps one of the distinguishing features of Automatic Statistician systems. But, as mentioned earlier, software this nature can serve other purposes as well. For example, users might be interested in raw predictions from the data (with or without explanations), or they might want the system to make data-driven decisions directly on their behalf.
Also, it is possible to build Automatic Statistician systems for model families
that are different from Gaussian processes or grammars. For example, we built
Automated Statistician systems for regression [5, 18], classification [12, 23],
univariate and multivariate data; systems based on various different model classes, and systems with and without intelligent resource control. This section discusses some of the design elements that are shared across many Automatic Statistician systems.

# 1 Core Components
One of the key tasks that an Automatic Statistician has to perform is to select,
evaluate, and compare models. These types of task can be run concurrently, but they have interdependencies. For example, the evaluation of one set of models might influence the selection of the next set of models.

# Effect of Perplexity
![](https://i.imgur.com/caduvgW.png)
![](https://i.imgur.com/yVeUlo4.png)
### **3️⃣ Intuition**

- Think of perplexity as **“effective number of neighbors”**:

Perplexity≈2H(Pi)\text{Perplexity} \approx 2^{H(P_i)}Perplexity≈2H(Pi​)

- Low → consider **few neighbors** → emphasizes local details
- High → consider **many neighbors** → emphasizes global relationships

---

### 🔹 **Kaggle Usage / Practical Tips**

- Typical range: **5–50** for tabular datasets; 30 is default
- Image embeddings (e.g., from CNNs) → sometimes higher (50–100) works better
- **Tip:** Run multiple perplexity values to see which reveals clusters or anomalies best

💡 **Key takeaway:**

> **Perplexity tunes t-SNE between local detail and global context.**  
> Low → detailed local clusters. High → coherent global structure.

|Parameter|Description|Effect|Kaggle Usage Tip|
|---|---|---|---|
|**n_components**|Dimension of reduced space (q)|Lower dimension → more compression, may lose information; higher → more faithful but less visualization-friendly|Often 2 or 3 for visualization; 10–50 if using as features for ML models|
|**n_neighbors**|Number of nearest neighbors used for adaptive similarity|Small → captures **local structure**, preserves small clusters; Large → captures **global structure**, smoother embedding|Tune based on problem: small for anomaly detection, moderate (15–50) for general clustering/visualization|
|**min_dist**|Minimum allowed distance between points in reduced space|Small → points tightly packed, dense clusters; Large → points more spread out, clusters looser|Lower values highlight fine-grained subgroups; higher for smoother, interpretable layouts|

# Binarization

**Note — Binarizing Count Features**

- Raw count features are often noisy, heavy-tailed, and dominated by outliers.
    
- Repeated interactions do not necessarily indicate stronger preference.
    
- **Binarization** converts counts to presence/absence:  
    [  
    x_{\text{binary}} = \min(x, 1)  
    ]  
    (0 → 0, ≥1 → 1).
    
- This focuses on _whether_ an interaction occurred, not _how many times_.
    
- Benefits: more robust features, reduced noise, better generalization.
    
- Commonly used for implicit feedback (clicks, views, purchases).
    
- Use counts only when frequency truly carries meaning (or apply log/TF-IDF).


# Quantization or Binning
## Fixed-width binning

- **Fixed-width binning** divides a numeric feature into bins of equal size.
    
- Each bin represents a **specific numeric range** (custom or automatically defined).
    
- Bins can be:
    
    - **Linearly scaled** (equal-width ranges)
        
    - **Exponentially scaled** (wider ranges as values increase)
        
- Example: age grouped by decades
    
    - 0–9 → bin 1
        
    - 10–19 → bin 2
        
    - 20–29 → bin 3
        
- Mapping a value to a bin:  
- $$
    [  
    \text{bin} = \left\lfloor \frac{x}{\text{bin width}} \right\rfloor  
    ]
    $$
- Useful for converting continuous variables into **categorical features** and reducing sensitivity to small numeric variations.
    



# Quantile binning

- **Fixed-width binning** is simple but can create many **empty bins** when data is sparse or highly skewed.
    
- This issue is addressed by **adaptive binning**, where bin boundaries depend on the **data distribution**.
    
- **Quantile binning** places bins so that each bin contains approximately the **same number of data points**.
    
- **Quantiles** divide data into equal portions:
    
    - Median → halves (50th percentile)
        
    - Quartiles → quarters (25%, 50%, 75%)
        
    - Deciles → tenths (10%, 20%, …, 90%)
        
- Overlaying quantile boundaries on a histogram reveals **skewness** and density patterns more clearly.
    
- Particularly useful for **heavy-tailed** or **imbalanced** count data (e.g., review counts).
    

**Key intuition:**

> Fixed-width bins preserve scale, while quantile bins preserve **data balance**.

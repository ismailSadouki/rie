# 6.2.1 | Nonlinear Features via Basis Expansions and Splines
> [!note] 🔧 What is Basis Expansion?
> **Basis expansion** is a technique used to make **linear models more flexible** by transforming the original predictors into a **higher-dimensional space** using **basis functions**.
> This allows **linear models** (like linear regression or logistic regression) to **capture nonlinear patterns** in the data — without changing the underlying linear algorithm!

![](https://i.imgur.com/PUvY6Hr.png)

### **Polynomial Splines**

Instead of using **one single polynomial** over the entire predictor range, **splines** break the range of `x` into **pieces (segments)** and fit **lower-degree polynomials (usually cubic)** in each piece.

- The breakpoints between these pieces are called **knots**.
    
- Within each region, the data is modeled with a **cubic polynomial** (that’s why we say _cubic splines_).
    
- These piecewise polynomials are **stitched together smoothly**, so the function is continuous and has continuous derivatives at the knots.
    

### 📌 Why use knots?

- **Knots** allow flexibility. You can model different behavior in different parts of the data.
    
- More knots → more flexible function (but also more risk of overfitting).
    
- Fewer knots → smoother, simpler curve (but might underfit).
    

The knots are typically chosen using percentiles of the data so that a relatively equal
amount of data is contained within each region. For example, a spline with three
regions typically places the knots at the 33.3% and 66.7% percentiles. Once the
knots are determined, the basis functions can be created and used in a regression
model. There are many types of polynomial splines and the approach described here is often called a natural cubic spline.




# Dimensionality Reduction Analysis


## 1. How Many Dimensions Are Needed?

the findings from PCA applied to all 150 features:
![](https://i.imgur.com/ntMbc80.png)

Just 4 components capture 80% of all variance. This is a remarkably low number for 150 features and strongly indicates that the dataset has a highly redundant feature space, many features are near-linearly correlated with each other.
![](https://i.imgur.com/EgsLj7e.png)

The scree plot shows PC1 alone explains 66.95% of variance, with a very steep drop-off afterwards. This is characteristic of datasets with one dominant latent factor driving most of the signal.
- **The elbow point** in the cumulative variance curve occurs around component 4–5, after which each additional component contributes diminishing marginal information.
- **Kaiser criterion** selects 15 components (eigenvalue > 1), which serves as a conservative but well-grounded recommendation for downstream modelling tasks.
- **Reconstruction error** (MSE vs. n_components) drops sharply from k=2 to k=10, then flattens  confirming that 20–25 components is the practical saturation point.

**Recommendation:** Use **k = 21 components** for tasks requiring high fidelity (95% variance), or **k = 15** (Kaiser) for a balanced compression suitable for classification pipelines.

## 3. Kernel PCA (Non-Linear Structure Test)

Kernel PCA was run with five kernels: `linear`, `rbf`, `poly`, `sigmoid`, and `cosine`.
![](https://i.imgur.com/XxnRAaw.png)

All kernel projections produce visually similar class distributions to standard (linear) PCA in 2-D. The `rbf` kernel does show marginally better class concentration than `linear`, but the separation remains poor across all kernels.

 The similarity between `linear` and `rbf` projections suggests the data does **not** contain strong non-linear structure that PCA is missing. And the dominant variance in this dataset is largely captured by linear combinations of features.

 
 Kernel PCA is therefore not recommended over standard PCA for this dataset in terms of class-discriminative structure.

## 9. Summary and Recommendations

### 9.1 What the Data Tells Us

This is a **highly redundant, low-intrinsic-dimensionality** dataset. Despite 150 raw features, 80% of the variance is captured by just 4 components. The dominant factor (PC1, 66.95%) represents a global baseline across many features simultaneously.  a sign of pervasive cross-feature correlation.

Class separation is **inherently difficult in low-dimensional projections** — neither linear nor non-linear 2-D embeddings cleanly separate Class 0 and Class 1. This suggests that classification likely requires higher-dimensional representations (15–21 components) and **non-linear classifiers.**

### 9.2 Method Recommendations

| Use Case                       | Recommended Method | n_components  |
| :----------------------------- | :----------------- | :-----------: |
| Downstream classification      | PCA                | 21 (95% var.) |
| Conservative feature reduction | PCA / Kaiser       |      15       |
| Interpretable latent structure | Factor Analysis    |      10       |
| Visualisation only             | UMAP               |       2       |
| Parts-based representation     | NMF                |     20–30     |
|                                |                    |               |

1. **95% variance requires 21 components** a 85.3% compression of the feature space (from 150 to 21 dimensions).
2. **PCA is the best method** for reconstruction fidelity and is appropriate for preprocessing before classification.
3. **UMAP (n_neighbors=15, min_dist=0.1) is the best visualisation** method — it reveals subpopulation cluster topology that t-SNE fragments and PCA flattens.
4. **Non-linear methods do not substantially improve class separation** over PCA, indicating the class boundary is not a simple curved manifold in feature space.
5. **Features with zero communality** in Factor Analysis (`rule_priority_KL`, `rule_doc_H`, `premium_per_coverage`) carry independent information and should not be dropped from a classification model even after PCA-based reduction.
6. **The data contains identifiable subpopulations** (visible in UMAP and t-SNE)  these may correspond to claim types, regions, or customer segments and could benefit from cluster-conditioned modelling strategies.

## 10. Extra Analysis 


### 10.1 Feature Correlation Structure

All 11,175 pairwise **Pearson** correlations computed across 150 features. Threshold for "highly correlated" set at |r| ≥ 0.85.
![](https://i.imgur.com/uM0qPRL.png)

Nearly half of all feature pairs exceed the 0.85 correlation threshold. This is an extraordinary degree of redundancy for a 150-feature dataset.


**this explains PCA's compression:** PCA identifies the shared direction of all ~75–100 near-perfectly-correlated features and compresses them into PC1. Because these features are essentially the same signal, PCA extracts their shared variance in a single component. explaining why PC1 alone captures 66.95% of total variance and why just 4 components suffice for 80%.


### 10.2 Classifier Performance: Raw Features vs PCA Reduction

![](https://i.imgur.com/c11uejK.png)
**Setup:** n = 20,000 samples, 5-fold stratified cross-validation. Three classifiers: Logistic Regression, Random Forest, MLP. Metric: ROC-AUC.

- **PCA-4 is too aggressive.** 
- **PCA-13 to PCA-21 closely track raw performance.** 
- **PCA-50 nearly equals raw features.** 


**Raw features are not dominated by PCA.** The best configuration per classifier is:
- LogisticReg: Raw (0.7220)  PCA provides no gain
- RandomForest: Raw (0.7229)  PCA provides no gain
- MLP: PCA-31 (0.7196) marginal +0.001 gain over raw (within noise)

For this dataset, PCA does not improve classification performance  it matches it at sufficient k. The value of PCA here is therefore **not accuracy** but **efficiency**: PCA-15 delivers 0.7156 RF AUC with 90% fewer features, cutting memory, training time, and inference latency. a meaningful engineering gain in production.

### 10.3 PC1 Uniform-Loading Diagnosis
**Setup:** Shannon entropy computed over absolute loadings per PC. Union-Find clustering applied at r ≥ 0.99 to find groups of perfectly-correlated features.
![](https://i.imgur.com/Bl8COf5.png)

![](https://i.imgur.com/W1Zhwz2.png)
**Entropy pattern across PCs:** PC1 has the highest entropy (4.69), confirming its flat loading across the big cluster. PCs 9 and 25 also show elevated entropy (~4.5), suggesting additional secondary clusters. PCs 13–16 show markedly lower entropy (~1.8–2.0), meaning those components load selectively on a small subset of features. these are the most interpretable PCs for domain analysis.

Also Despite 150 raw features, the dataset contains only 50 truly independent signals a 67% information redundancy rate. The 7 clusters account for 107 features (150 − 43 singletons), all of which collectively represent only 7 independent sources of variance. This is why PCA compresses so effectively: it is not losing information, it is removing duplicates.

### 10.4 Autoencoder vs PCA Reconstruction

**Setup:** PCA vs 5-layer MLP autoencoder (128 → 64 → k → 64 → 128) on n = 15,000 samples, 30 epochs. Encoding dimensions k ∈ {2, 5, 10, 21}.
![](https://i.imgur.com/kbhtxM3.png)

The autoencoder at k=21 achieves 0.013, which is lower. However, this advantage likely reflects **overfitting to the training set** rather than genuinely better compression: a 5-layer MLP with a 21-dimensional bottleneck has enough capacity to memorise local training patterns, whereas PCA is constrained to globally optimal linear reconstruction. The autoencoder's advantage at k=21 would likely not generalise as well to unseen data.

**PCA is recommended**. It wins at 3/4 encoding sizes, is deterministic (no training instability), requires no hyperparameter tuning, runs in milliseconds, and its k=21 MSE of 0.022 is already excellent.



## Final Conclusions

The dataset's 150 features reduce to **50 effective unique dimensions** (7 correlation clusters + 43 singletons at r ≥ 0.99). The dominant cluster alone contains 75 features that are near-perfectly correlated, essentially 75 rescaled copies of the same underlying variable. This explains every major observation in the analysis:
- Why PC1 captures 66.95% of variance (it aligns with the 75-feature cluster)
- Why PC1 loads uniformly at +0.0999 (entropy ratio = 0.936 ≈ uniform)
- Why 5,053 out of 11,175 feature pairs exceed |r| = 0.85

the best PCA configuration matches, but does not beat, raw features. Its value is engineering efficiency: **PCA-15 delivers equivalent accuracy with 90% fewer features**.

**Pipeline Recommendation**

`PCA(n_components=15)` for 95% variance or `n_components=31` for 100% which matches raw AUC exactly.

## 1. Optimal k Selection

**Setup:** n = 8,000 samples, PCA-30 dimensions. 

![](https://i.imgur.com/mBtD6fi.png)


**Elbow:** The visual elbow is at k=2, confirming that the dataset does not have many natural tight spherical clusters, large gains in compactness stop early.
![](https://i.imgur.com/3Np4dfp.png)

**Silhouette Score:** k=2 dominates at 0.6159. All values for k≥3 drop sharply , meaning splitting beyond 2 creates increasingly overlapping, poorly defined groups.
![](https://i.imgur.com/CHzwpGK.png)

**Davies-Bouldin Index:** Again k=2 wins with DB=0.5889. 
![](https://i.imgur.com/LV3IPdn.png)

**Calinski-Harabasz Index:** k=2 scores 18,624, nearly double k=3 (10,947) and far above all others. CH drops monotonically, confirming k=2 is the most compact and well-separated partition.
![](https://i.imgur.com/FUZoHGt.png)

**GMM BIC:** GMM BIC rewards model complexity and continues to drop as more Gaussians are added. 
The GMM BIC minimum at k=10 reflects probabilistic model fit, not natural cluster structure.
![](https://i.imgur.com/0nXlWVx.png)

**Gap Statistic:** Peaks at k=11, suggesting the data may have up to 11 statistically distinct groups compared to a uniform random reference. However, given the strong silhouette, CH, and DB consensus at k=2, this likely reflects the multi-scale subpopulation structure observed in UMAP/t-SNE rather than true discrete clusters.
![](https://i.imgur.com/YyYSFck.png)

**ARI & NMI vs Target:** 
All values near zero across all k. The clustering structure does not correspond to the binary classification target **clusters and class labels are essentially independent**. 
ARI values are slightly negative, indicating worse-than-random agreement. Which means the natural geometric groupings in the data do not align with Class 0 / Class 1.
![](https://i.imgur.com/CPFxeVD.png)

**Decision**

![](https://i.imgur.com/53wi69L.png)

All three internal geometric criteria unanimously select k=2. The two dissenting criteria (BIC, Gap) reflect model complexity and fine-scale topology respectively not the primary cluster geometry. <mark>k=2 is used for all subsequent analyses.</mark>

## 2. Hierarchical Clustering 

**Setup:** n = 3,000 samples, four linkage methods: Ward, Complete, Average, Single.

**Ward linkage:** 
The dendrogram shows a clear two-branch structure with a very large merge distance at the root . The two branches each contain many sub-merges at much smaller distances (100–200 range), indicating two internally coherent macro-groups with fine sub-structure within each.
it validates k=2 while hinting at sub-clusters within each group.
![](https://i.imgur.com/654noDY.png)

**Complete linkage:**
The more balanced branch sizes indicate complete linkage is finding comparably sized groups.
Root merge distance is much smaller than Ward's, suggesting complete linkage is more sensitive to outliers pulling branches together early.
![](https://i.imgur.com/5Xszsh9.png)

**Average linkage:** 
The branch structure is less symmetric than Ward, indicating some imbalance in cluster sizes under average linkage.
![](https://i.imgur.com/CnfN4k2.png)

**Single linkage:** 
Root merge distance ~20 but with a characteristic "chaining" pattern. one branch grows very gradually, absorbing singletons one at a time (the thin diagonal fan of merges at small distances). This is the classic single-linkage chaining effect, indicating the data does not have sharp boundaries. points are connected in a continuous chain rather than discrete blobs.
Single linkage is **not recommended** for this dataset.
![](https://i.imgur.com/oQKCgXi.png)


**conclusion**
All four linkages support a primary two-cluster structure. 
..Ward linkage is the most reliable choice for this data given its variance-minimisation objective and clean two-branch topology.

## 7. Summary

### 7.1 The Fundamental Finding

The dataset contains **one dominant geometric split (k=2)** that is robust across all clustering paradigms. This two-cluster structure corresponds to the bimodal PC1 distribution identified in the dimensionality reduction analysis. and represents a contrast between "standard claims" (Cluster 0, larger) and "high-premium cross-sell clients" (Cluster 1, smaller).

**this geometric split does not align with the classification target.** Both clusters are ~75–77% Class 1, and all external metrics (ARI ≈ 0, NMI ≈ 0) confirm the clusters carry no classification-relevant information.

### 7.2 Method Ranking

| Rank | Method                         | Silhouette | Recommendation                                 |
| :--: | :----------------------------- | :--------: | :--------------------------------------------- |
|  1   | **KMeans++ (k=2)**             |   0.6165   | Best overall fast, robust, identical to GMM    |
|  2   | **Agglomerative Ward (k=2)**   |   0.6157   | Best if hierarchy needed                       |
|  3   | **HDBSCAN**                    |   0.4526   | Best for density-based; finds 3 groups + noise |
|  4   | Agglomerative Complete/Average |   0.5321   | Poor CH; creates unequal groups                |
|  5   | DBSCAN (best config)           |   0.4841   | Useful for outlier detection (13.1% noise)     |
|  6   | OPTICS                         |  −0.5143   | Not suitable for this dataset                  |

### 7.3 Recommendations

**For downstream modelling:** Do not use cluster labels as features. ARI ≈ 0 means cluster membership adds no information about the target class.

**For customer segmentation:** The k=2 split is meaningful as a business partition  "standard claims" vs "high-premium cross-sell clients" even if it doesn't predict the target. Use Cluster 1 (higher premium, higher cross-sell index) to prioritise retention and upsell campaigns.

**For anomaly detection:** DBSCAN at eps=4.857 flags 13.1% of samples as noise/outliers. These border points may represent unusual or complex claims worth manual review.

**For sub-cluster exploration:** HDBSCAN (3 clusters) or GMM k=11 (fine-grained) reveal richer structure within the two main groups, consistent with the micro-clusters visible in UMAP. These may correspond to claim types, regional segments, or processing channels.

### 8.3 Feature Importance for Clustering
**Setup:** n=20,000 samples, Random Forest (200 trees) + KS test across all 150 features.

![](https://i.imgur.com/Jorycba.png)
The clusters are not driven by a combination of many features. they are driven by a single hard boundary in feature space. 
The RF Gini importances spread across 15+ features simply reflect the RF distributing its decisions across many correlated features that all encode the same underlying split.

**The KS statistic of 1.000 for all top features is the most revealing finding.** A KS statistic of 1.0 means the distributions of these features in Cluster 0 and Cluster 1 have **zero overlap**.  they are completely non-overlapping distributions. This is only possible if the two clusters are perfectly separated along these features in the original (pre-PCA) feature space.


### 8.4 Cluster Decision Boundary
**Setup:** Decision Tree (max_depth=4) and GBM trained to predict cluster labels from raw features.
![](https://i.imgur.com/Ts3Dg0e.png)
The two clusters are perfectly separated by a single threshold on one feature: `claim_to_premium_ratio <= -499.50`. A Decision Tree of depth 1 (one split) achieves AUC = 1.0 and classifies every sample correctly with zero error.

This explains everything observed previously:

- Why KS statistic = 1.000 for all top features (they are all correlated with `claim_to_premium_ratio`)
- Why bootstrap ARI = 1.0000 (the split is deterministic, not probabilistic)
- Why RF AUC = 1.0000 (trivial once the one rule is known)
- Why permutation importance = 0.0 (removing any one feature doesn't change predictions since others encode the same rule)
- Why the centroid heatmap shows ±1.00 on all features (perfect anti-correlation imposed by the split)
